# W3C document type definitions

Unit tests check Dogear's DAISY 2.02 files against these, offline. The DAISY 2.02 spec
(Appendix 3) says its NCC and text documents validate against the XHTML 1.0 Transitional
DTD, and its SMIL files against the SMIL 1.0 DTD.

The files are unmodified copies, downloaded 2026-10-27:

| File | From |
|---|---|
| `xhtml1-transitional.dtd`, `xhtml-lat1.ent`, `xhtml-symbol.ent`, `xhtml-special.ent` | <https://www.w3.org/TR/xhtml1/DTD/> |
| `SMIL10.dtd` | <https://www.w3.org/TR/1998/REC-smil-19980615/SMIL10.dtd> |
