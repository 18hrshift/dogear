Help

Make a book

  1. On Your books, choose a book file and upload it. Dogear reads EPUB, PDF, MOBI, and AZW3 files.
  2. Dogear reads the book to find its chapters. Then choose what to make, the voice, the speed, and which sections to read.
  3. Choose Start making. A long book takes hours. The book's page says how far it has got, and you can close the page and come back.
  4. When it's ready, download what Dogear made from the book's page.

If Dogear can't read a book

The book's page says why, and what to do. Once that's done (for a Kindle book, say, installing Calibre), choose Read again on the book's page.

Stopping and starting again

Stopping a book is safe. Every sentence Dogear has spoken is kept, so Start again carries on where it stopped.

Dogear makes one book at a time. Other books wait their turn.

Using Dogear from a phone

Start Dogear on the computer with dogear serve --lan. It shows a second link for phones and other computers on the same network. Open that link on the phone. Anyone on the network who has the link can use Dogear, so share it only with people you trust.

Keep Dogear running

This page works only while Dogear is running on the computer. Keep its window open. To stop Dogear, press Ctrl+C in that window. A book being made stops too, and Start again carries on later.
